# AURA

> **Personal AI Assistant for Windows**

AURA is a private, local-first AI assistant designed to act as a personal control center on Windows.

It combines voice interaction, artificial intelligence, Google services and Windows system tools into a single assistant.

## ✨ Planned capabilities

* 🎙️ Voice interaction
* 🧠 AI-powered conversations
* 📧 Gmail integration
* 📅 Google Calendar integration
* 💻 Windows system control
* 📁 Local file management
* 🧠 Local memory
* 🔔 Windows notifications
* 🌐 Web capabilities
* 🔐 Secure Google OAuth authentication
* ⚙️ Custom tools and commands

## 🏗️ Technology

* Python
* Gemini API
* Google APIs
* Google OAuth 2.0
* SQLite
* Windows APIs
* Local speech technologies

## 🔒 Privacy

AURA is designed primarily for private, personal use.

Sensitive credentials, API keys and authentication tokens are kept locally and must never be committed to the repository.
